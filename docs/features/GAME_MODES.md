# Game modes

The mode menu is shown before the first run and can be reopened with the
`☷ Mode` button.

- **Classic:** standard play with the ghost landing guide.
- **Invisible:** standard rules with locked cells and the ghost guide hidden;
  the player must remember the stack. A line-clear snapshot flashes briefly
  before hiding resumes.
- **Sprint:** standard visible board with a 40-line target and elapsed timer.
  The run ends when the target is reached or the player gets game over.

The mode changes presentation and run objectives only. Board collision, piece
geometry, scoring, and gravity remain shared.
